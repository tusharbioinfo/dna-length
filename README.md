#DNA Length & GC Content Analysis

A simple Python-based bioinformatics tool for calculating the length and GC content of a DNA sequence.

**Workflow**

DNA Sequence

     ↓
Sequence Processing

     ↓
DNA Length

     ↓
GC Content Calculation

     ↓
Results

**Repository Structure**

dna-length/

├── README.md

└── length & gc_count.py

**Installation**

Clone the repository:

git clone https://github.com/tusharbioinfo/dna-length.git

cd dna-length

Usage-

Run the Python script:

python "length & gc_count.py"

Input-

A DNA nucleotide sequence containing A, T, G and C bases.

Example:

ATGCGTACGTTAG

Output

The program calculates:

DNA sequence length,
GC content (%)
Applications
Basic DNA sequence analysis
GC content analysis
